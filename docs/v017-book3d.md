## 1. 아이가 보는 것

| 기능 | 3D 마을 | 그림 화면(3D를 못 쓰는 기기) |
|---|---|---|
| 쪽지 종이 | 정답 화살에 쓰러진 몬스터 자리에 접힌 종이(빨간 봉인)가 1.4초 동안 팔랑이며 내려앉는다. 땅에서는 살랑이고 아래에 옅은 빛, 가끔 반짝. 누르면 깡충 뛰고 아래 상태 줄에 "📜 늑대가 떨어뜨린 이름 쪽지예요. 곧 쪽지 문제가 나와요". 그 쪽지 문제가 나오면 위로 날아오르며 사라진다(주워 읽음). 읽지 않으면 90초 뒤 작아지며 사라진다 | 같은 자리(늑대와 같은 % 변환)에 📜가 살랑 |
| 기억 늑대 팻말 | 기억 늑대 문제 동안 늑대 한 마리 머리 위에 빈 나무 팻말(옅은 하늘색 판 + 흰 마름모, 글자 없음)이 떠 있고 발밑에 하늘색 고리. 그 문제를 한 번에 맞히면 팻말을 땅에 내려놓고(반짝) 곧 사라진다 | 그 늑대 위에 작은 하늘색 팻말 |
| 친구 방문 | 늑대·늑대 왕·여우가 없는 틈에 수첩에서 친구가 된 몬스터 한 마리가 열린 늑대 길을 따라 숲에서 걸어와 울타리 밖에서 아이(화면) 쪽을 보고 깡충깡충 인사하고 돌아간다. 몬스터 모형 그대로(따뜻하게 밝힌 색, 꼬리를 흔들고 고개를 갸웃, 입은 살짝 웃음), 발밑 분홍 고리, 리본을 단 친구는 목에 리본. 상태 줄 "👋 친구 보리가 놀러 왔어요" | 친구 그림 문자가 같은 자리에서 걷고, 인사할 때 깡충 |

- 3D에 글자를 그리지 않는다. 쪽지·팻말 모두 코드 도형(geo.js `solid`), 친구는 저장소의 몬스터 모형(코드 모형 6종 + 0.15 GLB 늑대 왕·도둑 여우)을 다시 쓴다. 새 이미지·생성 서비스 없음.
- 경제·전투에 영향 없음: 금화·일제 사격·늑대 경로는 그대로다. 소리도 새로 내지 않는다(읽는 중 띠·소리 없음 원칙). 상태 줄 문구는 낮은 순위라 부서짐·여우 같은 알림을 가리지 않는다.
- 움직임 줄이기: 팔랑임·깡충·살랑이 없이 제자리에 놓이고, 사라질 때도 바로 사라진다.

## 2. 구조(누가 무엇을 하나)

| 파일 | 역할 |
|---|---|
| `book.js` | `FLAGS.book3d`(기본 켬, `?book3d=0`), `BOOK.SCENE` 수치, `Book.visitPick(b, {seed, run, n, last})`(순수 함수). 친구 카드를 받은 **모든 종** 가운데 고르고, 바로 전 친구는 둘 이상이면 피한다. 난수는 `seed`(판의 문제 순서 씨앗)·`run`(판 번호)·`n`(방문 수)의 해시에서만: 세계 난수(`world.rng`)·기록 난수(`b.rng`, 반짝 손님)를 건드리지 않고 기록도 바꾸지 않는다 |
| `index.html` | 장면 상태 `b3`(저장하지 않음). `b3Tick()`이 세계 한 틱 뒤 불려 세계를 **읽기만** 해서 종이 수명·팻말 늑대·친구 걸음을 정한다. `window.getBook3dState()`로 3D에 넘기고, 일회성 연출은 `VillageView.events`로 `noteDrop{kind,x,z,id}` · `noteRead{id}` · `signDown{wolf}` · `visitHello{id,kind}`. 그림 화면 표시는 `b3Draw()`(frame에서) |
| `src/book3d.js`(새) | 3D 렌더만: 종이 2장 풀, 팻말 1개, 종류별 친구 인스턴스 메시(무리 메시의 지오메트리를 복제하고 자세 칸만 새로, 재질은 같이 씀), 리본 메시. `VillageView.inspect().book3d`로 검사 값 |
| `src/village.js` | 연결 7줄: 가져오기 1 · `book3d({...})` 생성 1 · `events` 끝 `B3.events(list)` · `step`에 `B3.step(fdt)` · `frame`의 스프라이트 단계 `B3.sprites(less)` · 캔버스 누르기 `B3.tap` · `inspect` 감싸기 1. 0.16의 `noteDrop` 가운데 반짝이 줄은 지움(book3d.js가 자리 없는 사건이면 같은 반짝이를 낸다) |

`getVillageState()`의 긴 줄은 다른 작업(늑대 예고)과 겹칠 수 있어 고치지 않고, 3D가 따로 `window.getBook3dState()`를 읽는다. 새로 배포하는 파일은 없다(`src/book3d.js`는 esbuild가 `village.js`에 묶는다. `scripts/build-pages.cjs`·`test.cjs` 허용 목록·워크플로는 `src/**`로 이미 덮여 그대로).

## 3. 규칙(장면 전용, `Book.BOOK.SCENE`, 틱 = 0.1초)

| 칸 | 값 | 뜻 |
|---|---|---|
| `note` | 900 | 종이가 땅에 남는 틱(90초). 그 쪽지 문제가 나오면 그 전에 사라짐 |
| `edge` | 3.5 | 종이를 놓는 가장 먼 자리 = 마을 반지름 + 3.5(숲 쪽에서 쓰러지면 같은 방향으로 당김, 화면 안) |
| `sign` | 30 | 기억 늑대 문제가 시작된 뒤 처음 오는 늑대가 팻말을 든다. 3초 안에 새 늑대가 없으면 울타리 밖에서 다가오는 늑대 가운데 가장 바깥. 팻말 늑대가 쓰러지면 팻말도 떨어지고 다른 늑대로 옮기지 않는다 |
| `quiet` | 30 | 늑대·왕·여우가 없는 틈이 3초 이어져야 방문(결전 앞뒤 `bell` 1·2·3 제외) |
| `first` / `gap` / `jitter` / `free` | 300 / 600 / 300 / 200 | 첫 방문은 30초 뒤, 다음 방문은 60~90초 뒤(가끔), 더 놀기(늑대 없음)는 20~50초 |
| `r0` / `r1` / `walk` / `stay` / `run` | 6 / 1.3 / 0.14 / 30 / 2 | 숲 쪽(반지름 + 6)에서 울타리 밖(반지름 + 1.3)까지 초당 1.4로 걸어와 3초 인사, 돌아감. 한 번 약 10초. 늑대가 나오면 곧바로 두 배 빠르기로 돌아감 |
| `river` | 50 | 물레방아 마을부터 강 쪽(강 방향 50° 안) 길은 고르지 않음(친구가 물을 건너지 않게) |

- 처음 문제 3개 보호(`w.calm`) 등 세계 규칙과 무관하게 장면만 본다. 쉬는 동안(잠깐 쉬기·쉬기 화면·시작 화면)은 틱이 돌지 않아 친구·종이도 멈춘다.
- 새 마을·처음부터·더 놀기·진행 파일 바꾸기(`resetView`)에서 장면 상태를 비운다.

## 4. 결정성(세계 지문)

- `b3Tick`은 세계를 읽기만 한다(`world.wolves`·`king`·`fox`·`nextId`·반지름·열린 길). 세계·판 저장·기록에 쓰지 않고 `Math.random`도 쓰지 않는다. 친구 고르기·길·간격은 `Book.visitPick`의 해시 난수.
- 검사(test-dom M-13 끝): 같은 시각·같은 손길로 켬과 `?book3d=0`을 돌려(조용한 틈 450틱 + 늑대 무리 2,500틱, 500틱마다 6번) 세계 JSON 지문 · 판 상태 · 기록이 한 글자도 같다. 켠 쪽에서 친구 방문·쪽지 종이가 실제로 일어났는지도 확인한다.

## 7. 남은 것

- 명세의 "반짝 모습으로 놀러 오기"(수첩 켜기 단추, 기본 끔)는 만들지 않았다. 친구는 늘 평소 색(따뜻하게 밝힘)으로 온다.
- 명세 §1.3의 "친구가 된 순간 그 종류의 살아 있는 몬스터가 꼬리를 흔들고 숲으로 돌아감"은 세계를 바꾸는 일이라 하지 않았다(이번 범위는 장면 전용).
- 기억 늑대가 한 번에 맞히면 "물러난다"(명세)는 세계 규칙을 바꾸므로 하지 않았다. 팻말만 내려놓는다.
- 실기기·패드에서 종이·팻말·친구 크기와 눈에 띄는 정도는 사람이 확인해야 한다(CI SwiftShader 캡처만 봄).
