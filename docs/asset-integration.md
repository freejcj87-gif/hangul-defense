# 원본 아트 연결 계획과 확인 상태

확인된 참고: freejcj87-gif/coopnight-web의 크림·녹색·금색 UI와 마을 테마.
해당 저장소 Art 디렉터리에는 로고·로딩·시작 배경 7개가 있었으나, 캐릭터·건물·애니메이션 원본과 사용 범위는 미확인입니다.
NotoSansCJK-OFL은 폰트 문서이며 다른 아트의 라이선스 근거로 사용하지 않습니다.

## 원본 작업 세션 — 사용자 지정 출처

2026-11-11 사용자는 기존 아트를 작업한 세션을 **Game Project Brand new**로 명시했습니다. 사용자가 아트 위치를 모르는 상태로 취급하거나 공유 링크를 다시 요구하지 않습니다.

2026-11-04 대화 기록에서 확인한 위치 단서:
- PC Codex 앱 → `.claude` 프로젝트 → **Game Project Brand new**
- 스레드 ID: `01a0ea47-ecb1-7df0-bf90-ce53bc9dab30`
- 이는 과거 세션 확인 기록이며, `.claude`는 당시 앱의 프로젝트 표시명입니다. 실제 아트 파일의 절대 경로는 아닙니다.
- 이전 **Game project 3 문제점 파악** 세션과 혼동하지 않습니다.

현재 상태는 **원본 작업 세션 특정 / 현재 세션에서 원본 파일 직접 조회 통로 미제공**입니다. 원본 부재를 의미하지 않습니다.
세션/환경 접근 도구가 있는 작업 경로에서 이 정확한 세션을 대상으로 자산 목록과 사용 범위를 읽기 확인한 뒤, 필요한 아트만 별도 개발 저장소에 복사하는 것이 다음 단계입니다.
기존 로컬 프로젝트에 대한 접근 거절은 우회하거나 재시도하지 않습니다.

## 이번 처리
CSS로 새 집·타워·지형을 만들고 임시 늑대 이모지를 유지했습니다.
기존 원본 이미지를 복사하거나 외부 이미지 URL에 연결하지 않았습니다.
접근이 거절된 로컬 CoopNight 프로젝트를 재시도하지 않았습니다.

## 원본 확보 후 인계
각 자산의 원본 경로, 제작자/구매 출처, 새 프로젝트 사용 가능 범위, 크기, 프레임 수, 앵커와 투명도 기록.
house / tower(level 0~5) / wolf(idle, walk, hit, retreat) / terrain / hit effect 역할에 연결.
게임 규칙은 combat.js에 유지하고 화면만 교체.
320/390px와 데스크톱에서 잘림, 체력바·글자 가독성, 터치 영역 검증 후 적용.

## 실제 기기 확인
Android Chrome과 iPhone Safari에서 첫 터치 음성 시작, 한국어 음성 존재/없음,
효과음 켜기·끄기, 배경 전환, 세로·가로 회전, 저장 재개를 확인.
자동 에뮬레이션 결과를 실기기 검증으로 표시하지 않습니다.
