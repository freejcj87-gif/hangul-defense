# 살아 움직이는 마을 (0.4 → 0.6)
사용자가 원본 꼬꼬마을의 살아 움직이는 농장 체감을 요청하여, 원본 공개 showcase를 읽기 전용으로 확인한 뒤 실제 인계 GLB를 재사용했다.
- 원본: art-handoff/coopnight/source-3d/models/environment-pack.glb. EnvCoop/EnvMarket/EnvTower/EnvCornTower/EnvChicken/EnvChick/FarmerPolished/EnvFence/EnvGate/EnvTree/EnvBush/EnvRock를 재사용.
- 절차 애니메이션: 닭의 배회와 뛰기, 농부 이동/팔·다리/알 운반, 나무 흔들림, 연기, 씨앗 발사, 금화 이동, 타워 반동.
- 주민 일상은 장식이며 자동으로 골드를 생성하지 않는다. 학습·전투·보상 규칙과 기존 저장 키는 유지.
- 3D 늑대는 새 절차 모델이다. 기존 Unity의 늑대 모델/애니메이션을 가져온 것으로 주장하지 않는다.
- 원본 Unity 코드나 로컬 프로젝트는 변경하지 않았다. Unity 빌드를 iframe으로 감싸는 방식이 아니라, 공유된 자산으로 한글 학습 게임 장면을 구현했다.
- WebGL/GLB 로드 실패 시 기존 PNG 장면에서 게임을 계속할 수 있다. 움직임 줄이기와 일시 정지는 주민·전투 연출에도 적용된다.
- 0.5 짓기 연출: `VillageView.build('tower'|'chicken'|'fence')`. 타워는 바닥 빛 → 빛기둥과 먼지 → 솟아오름과 별, 닭은 빛 → 깃털과 점프, 울타리는 망치질과 나무 조각. 예고 → 충격 → 여운 순서이며 움직임 줄이기에서는 완성 상태로 바로 나타난다. 깃털 그림은 인계 자산 `browser/animation/fx-feathers.png`.
- 0.5 장면 정리: 390px 폭 기준으로 카메라·배치를 다시 잡고 GLB 메시를 버텍스 컬러로 병합해 드로우콜을 줄였다. 파티클 상한 300.
- 실행 시 외부 CDN 없음. Three.js 0.180.0과 esbuild 0.25.10을 CI에서 번들링하며 Three.js 라이선스를 배포물에 포함한다.
- 0.6 실시간 늑대: 늑대 위치는 규칙의 진행률(경과/제한)로만 정해진다. 풀이 중에는 0.1초 단위로 끊기는 시계를 약 0.2초 안에 따라붙게 보간하고, 카드 고르기·쉬기·배우기에서는 정확한 위치에 멈춘다. 출발점은 390px 폭에서 5마리가 모두 보이도록 SPAWN_X 2.9로 옮겼다. 늑대는 인스턴스 메시로 그려 마릿수와 관계없이 드로우콜이 거의 늘지 않는다. 0.5의 체력 바와 전투 단계 의존은 없앴다.
- 0.6 연출: 정답이면 타워가 늑대마다 알 포탄을 쏘고 늑대는 머리 위 별과 함께 기절해 멈춘다. 한 번 틀리면 늑대가 점프하며 성큼 다가온다. 늑대가 도착하면 타워가 층 수만큼 쓰러뜨리고 나머지는 울타리를 넘어 마당으로 들어와 닭을 놀래킨다. 숨은 닭은 닭장 벽에 웅크려 회청색으로 바래고 떨며, 돌아올 때 깡충 뛴다.
- 0.6 생산 연출(약 2초): 닭이 알을 내고, 알이 농부 바구니로 날아가고, 농부가 가게로 뛰어가면 가게가 흔들리며 동전이 터진다. 연못이 있으면 물고기도 뛴다. 움직임 줄이기에서는 가게의 정지 동전 한 장면만 보인다. 화면 위 글자 띠(🥚 → 🧑‍🌾 → 🏪 → 🪙)는 3D·그림 화면·움직임 줄이기 모두에서 같은 순서로 나온다.
- 0.6 새 시설: 고용 농부(최대 2명, 길을 나눠 다님), 연못(3단계, 연잎·갈대·잔물결), 마을회관 단계에 따른 보육 닭장·건초·헛간과 커지는 본 닭장, 잔치 깃발 줄. 연못·회관·잔치는 새 아트가 아니라 기존 GLB 노드와 기본 도형 조합이다.
- 0.6 기타: 타워를 눌러도 흔들림과 반짝임만 있고 아무것도 사지 않는다. WebGL 컨텍스트를 잃거나 프레임 루프에서 예외가 나면 그림 마을로 넘어간다. 장면은 `#villageStatus`에 글을 쓰지 않는다(문구는 index.html이 담당).
- 0.6 남은 것: 기본 농부가 가끔 1층 타워 뒤로 가려진다. 늑대 5마리가 모두 쓰러지면 대문 앞이 붐빈다. 회관 3단계 없이 잔치만 있는 상태(정상 흐름에서는 생기지 않음)에서는 깃대가 조금 떠 보인다.
