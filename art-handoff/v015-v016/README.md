## 게임에 연결할 때

- **좌표와 축척.** glTF의 +Y가 위다. 바퀴 단독 파일을 제외한 8개 파일은 배치 원점이 지면 중심이다. `manifest.json`의 `world_bounds_min/max`를 참고한다. 현재 0.14에서 닭장을 높이 2.7로 불러오는 기준과 비교해 성 높이는 약 4.1, 물레방아는 약 2.2로 제작했다. 다리 양 끝의 지면 높이와 성벽의 실제 배치 간격은 0.15·0.16 지형 규칙에 맞춘다. 충돌과 통행은 게임에서 정한다.
- **바퀴.** `WaterWheel` 노드의 로컬 X축이 회전축이다. 완성형 안에서 노드 피벗은 `[-1.16, 0.92, 0]`이고, 분리형에서는 `[0, 0, 0]`이다. `WheelTurn`은 6초 회전 루프다. Three.js에서 클립을 재생하거나 노드의 `rotation.x`를 직접 제어한다. 바퀴 방향을 바꿀 때는 회전 속도 부호를 바꾼다.
- **늑대 왕·여우.** 정면은 +Z다. `Trot`은 0.96초 제자리 속보로, 머리·꼬리·네 다리에 노드 키프레임이 있다. 월드 위치·회전·속도, 공격과 피격 연출은 게임에서 제어한다. 복제 개체별로 `AnimationMixer`를 사용하려면 각 개체의 노드를 유지한다.
- **드로우콜과 로더.** Three.js의 `GLTFLoader`에서 GLB를 바로 읽을 수 있다. `COLOR_0` 버텍스 색과 단일 무광 재질을 쓰며 외부 텍스처 요청은 없다. 정적 모델당 1개, 물레방아 2개, 동물은 각각 7개 메시다. 그림자 패스는 별도다. 다수 배치하는 성벽은 같은 지오메트리를 인스턴싱할 수 있다. 애니메이션 대상 부품은 기존 정적 `bake()`로 병합하면 분리 동작을 잃는다.
- **PNG 대체 화면.** 건물과 캐릭터는 0.14의 `(-9, 14, 16)` 정면 왼쪽 카메라 각도로 렌더했다. 단독 바퀴는 원판이 보이는 각도를 사용했다. 알파 경계와 GLB 원점 투영 위치(`png_origin_xy`, 왼쪽 위 기준)는 manifest에 있다. 파일별로 여백을 맞춰 렌더했으므로 배치 크기는 PNG 픽셀 수만 비교하지 말고 월드 치수에 맞춘다.

## 출처와 제작 원본

한글 디펜스용 창작 모델이다. 기존 `environment-pack.glb`는 색감·형태 참고로 확인했다. 외부 모델·텍스처·이미지 서비스는 사용하지 않았다. 패키지 안의 파일은 한글 디펜스 개발·테스트·배포에 적용할 수 있다. [메시 제작 원본](build_models.py)과 [내보내기 스크립트](export_pack.py)는 형태·배색 수정용이다. Python 3.10+와 NumPy·Pillow가 있으면 `python -B export_pack.py`로 다시 생성할 수 있다. 미리보기 글꼴은 Windows Segoe UI다.

`node check_pack.mjs <게임의 node_modules 절대 경로>`로 기존 Three.js 로더에서 9개 파일의 로딩, 삼각형 수, 경계, 성문 개구부, 클립 재생과 루프를 검증한다. 이 인계는 에셋 단위이며 인게임 연결과 Android 성능 검증은 해당 버전에서 한다.
