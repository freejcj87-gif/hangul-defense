# 사용 범위와 적용 메모

이 패키지의 사용 목적은 한글 디펜스 비공개 개발·테스트와 아트 통합이다. 각 파일의 실제 CoopNight 원본 경로와 출처 문서는 [manifest.json](manifest.json)에 기록했다.

## 출처별 범위

- **Higgsfield 이미지·영상 및 파생 PNG.** CoopNight에서 사용자 요청으로 제작한 이미지·모션 원본과 그 원본을 다듬은 아이콘·텍스처다. 2026-11-11 확인한 Higgsfield 약관 §4.4는 서비스가 출력의 소유권을 주장하거나 상업적 이용을 제한하지 않는다고 설명한다. §4.2·§5.5·§13.2 등은 입력과 결과물에 대한 제3자 권리 확인 및 필요한 표시를 사용자 책임으로 둔다. 공개·상업 배포 전에 참조 입력의 권리와 출처 표시 조건을 확인한다. [Higgsfield 이용약관](https://higgsfield.ai/terms-of-use-agreement)
- **Blender 모델.** `farmer`와 `environment-pack`은 3D Jutsu Blender에서 CoopNight용으로 제작됐다. 원본 PROVENANCE는 외부 구매 모델·텍스처 없이 제작한 사실을 기록한다. 농부는 기본 자세, 마을은 배치 장면으로 제공된다. 편집은 BLEND, 교환은 GLB를 사용한다.

## HTML 통합

1. **마을.** 초원 PNG를 배경으로 놓고 중앙 빈 영역에 집과 타워를 배치한다. 이미 그려진 나무·다리·울타리는 장면의 일부다. 이동과 충돌에 필요한 좌표는 한글 디펜스에서 정한다.
2. **캐릭터·건물.** 투명 PNG에는 50% 알파 기준 경계 상자가 기록돼 있다. HTML 좌표 원점 기준 `[left, top, right, bottom]`이다. 바닥에 닿는 오브젝트의 초기 앵커는 경계 상자 하단 중앙을 쓰고 실제 그림을 보고 조정한다. 초상과 UI 아이콘은 중심 정렬한다.
3. **타워·집 레벨.** 타워 01~10과 집 01~05는 CoopNight 외형 번호다. 한글 디펜스의 초기 상태와 업그레이드 단계에서 어떤 아이콘을 보여줄지 별도로 매핑한다.
4. **늑대.** 전면 초상은 투명 PNG다. 전신 원본은 방향과 반투명 광륜이 남은 콘셉트 시안이다. 이동용 전신 연속 프레임에는 통일된 방향·발 기준선·실제 루프를 맞춰야 한다.
5. **애니메이션.** 금화는 `front → quarter → edge → reverse-quarter` 개별 그림을 반복할 수 있다. 착탄·먼지·고리는 정적 파티클이며 지속 시간과 변형은 구현에서 정한다. 알껍질·깃털 PNG는 2×2 칸의 개별 모양이다. 늑대·보스 MP4 6개는 자세와 예비동작 참고용이다. 걷기 영상은 중간에 바라보는 방향이 바뀐다.
6. **3D.** 마을 GLB는 여러 오브젝트가 놓인 합본이다. 닭장·시장·타워·울타리·문·나무 등을 각각 쓰려면 모델에서 해당 노드를 선택하거나 일관된 각도로 2D 렌더를 뽑는다. 농부와 마을 GLB 양쪽에서 외부 URI 0개와 애니메이션 채널 0개를 확인했다. 기존 Unity의 절차 모션은 프로젝트 코드에 있다.

브라우저용 스프라이트 루프 제작과 한글 디펜스 화면 연결은 후속 통합 작업이다. 이번 검증은 이미지 디코드·알파, 영상 규격, GLB 구조, 원본 및 복사본의 해시 일치 범위다.
