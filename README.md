## 이번 장면
꼬꼬마을에서 인계한 실제 3D 모델로 농장 장면을 구성했습니다. 닭·병아리 배회, 일꾼 이동과 알 운반, 나무와 연기, 타워 발사·반동, 금화 연출을 포함합니다.
0.12에서는 한 판에 끝(엔딩)이 생겼습니다. 마을에 지은 것이 66개가 되면 늑대 왕이 숲 가장자리에 와서 기다리고, 값 없는 🔔 종을 누르면 결전입니다. 한 번에 맞힐 때마다 별 방패가 하나씩 깨지고 6개를 깨면 왕이 달아납니다(지는 경우·시간 표시 없음). 엔딩 카드에서 새 마을(초원 → 채석장 → 서리 과수원 → 불씨 숲)로 떠나거나 이 마을에서 더 놉니다. 판 중간에는 도둑 여우가 세 번 와서, 맞히면 황금 화살이 쫓아냅니다. 경제도 고쳤습니다: 정답 금화는 글 길이와 무관하게 같은 금액, 가격은 15~350으로 납작하게, 회관은 지은 수 10·32·54에서 저절로 커지고, 새 판은 타워 2개로 시작하며, 늑대 무리 간격은 그 나이 문제의 읽기 박자(13~45초)를 따릅니다. 보통 아이는 나이와 상관없이 약 85문제에 엔딩을 봅니다(시뮬레이션, 가정값). 예전 저장은 이어서 할 수 있고 금화만 4분의 1로 환산됩니다. 정본은 [기획서 §11](docs/game-plan.md).
0.11에서는 듣고 고르기 모드와 그 문항을 없앴습니다(프로듀서 결정, 2026-11-13). 시작 화면에서는 나이만 고르고, 게임은 언제나 글을 읽고 고릅니다. 읽어 주는 음성도 없앴습니다(다시 듣기 버튼, 틀린 뒤 정답 읽어 주기, 7세 질문 읽어 주기, 말풍선 눌러 듣기, 읽는 속도 설정). 틀린 뒤에는 초록색 정답을 보여 주고 잠깐 뒤 그 답을 누르면 다음 문제로 갑니다. 효과음은 그대로입니다. 예전 듣고 고르기 저장은 금화와 마을 그대로 읽고 고르기로 이어집니다. 내용은 [기획서 §10](docs/game-plan.md)에 있습니다.
0.10은 자동 플레이 점검(7~10세, 마을을 끝까지 키워 봄) 결과를 고친 판입니다. 늑대가 가까이 온 닭만 숨어 큰 마을에서도 닭이 보이고, 새 판은 처음 3문제 동안 늑대가 쫓기만 하며 마지막 닭 한 마리는 늘 지켜집니다. 효과음은 간격을 두고 문제를 듣는 동안·정답 직후에는 전투음이 쉬어, 정답 소리가 잘 들립니다. 같은 말풍선은 무시하면 회관 단계마다 두 번까지만 나오고, 9세 이상 읽기는 틀린 뒤 질문과 정답만 짧게 읽어 줍니다. 보기가 열리기 전에 마구 누르면 금화가 줄고, 판마다 문제 순서가 바뀌며 문제은행이 늘었습니다. 근거와 수치는 [기획서 §9](docs/game-plan.md)에 있습니다.
0.9에서는 프로듀서의 5대 방향([기획서](docs/game-plan.md))을 넣었습니다. 위쪽 시간 바가 없어지고 늑대는 나이별 세기로 계속 몰려옵니다(숲 쪽 붉은 발자국과 울음으로 알림). 한 번에 맞히면 닭이 알을 낳고 농부가 바구니에 담아 매대에 팔며, 동전이 금화 칸으로 날아갑니다. 장면 아래 상점 2줄은 늘 열려 있어 언제든 타워·닭·농부·울타리·강화·회관을 살 수 있고(타워 20개·닭 20마리까지, 개수는 보이지 않음), 꼬꼬 말풍선이 금화에 맞춰 살 것을 추천합니다. 시장은 회관 단계마다 커지고 울타리는 3겹까지 두꺼워집니다.
0.8에서는 늑대가 쉬지 않고 옵니다. 무리는 13~20초마다, 그 사이에도 낙오 늑대가 계속 숲에서 나옵니다. 마을회관을 키우면 덤불 늑대·멧돼지·바위 늑대·서리 늑대와 우두머리 불씨 왕이 차례로 나오고, 타워 강화 카드로 터지는 화살(펑 화살 → 큰 펑 화살 → 세 갈래 화살)을 얻습니다. 빨리 맞힐수록 일제 사격이 많고, 연속으로 맞히면 금화가 늘며, 긴 글을 맞히면 카드를 여러 장 고릅니다. 4문제마다 상식·수학·영어 문제가 섞입니다. 규칙과 밸런스 근거는 [설계 문서](docs/village-defense-design.md)에 있습니다.
0.7에서는 늑대 무리가 사방에서 무작위로 몰려와 닭을 물어 가고 건물을 부숩니다. 처음에는 화살 타워 1개가 막고, 문제를 한 번에 맞히면 모든 타워가 일제 사격을 하며 금화로 타워·울타리·닭을 늘립니다. 마을이 커지면 카메라가 뒤로 물러나고 늑대도 훨씬 많이 옵니다. 시간 바는 다음 늑대 무리가 마을에 닿기까지 남은 시간입니다. 규칙은 [0.7 설계](docs/village-defense-design.md)에 있습니다. 아래는 0.6 때의 설명입니다.

0.6에서는 문제마다 제한시간이 있고, 시간 바와 마을에서 늑대가 실시간으로 다가옵니다. 한 번에 맞히면 늑대와 시간이 멈추고, 닭이 낳은 알을 농부가 팔아 금화가 생기며, 카드 3장 가운데 하나를 골라 지으면 바로 다음 문제로 갑니다. 마을회관을 키우면 농부·연못·잔치 카드가 열립니다. 규칙은 [0.6 설계](docs/realtime-loop-design.md)에 있습니다.
저장 형식은 0.5와 호환됩니다. 주민의 생활 동작은 장식이며 시간이 지난다고 금화가 생기지 않습니다.
원본 Unity 프로젝트는 수정하지 않았습니다. 자세한 자산/동작 범위는 [장면 구현 메모](docs/living-village.md)를 참고하세요.

## 로컬 실행
Node.js 22와 Python 3 기준:
```sh
npm install --no-save --package-lock=false three@0.180.0 esbuild@0.25.10
node scripts/build-pages.cjs
python -m http.server 8000 --directory .pages-build
```
http://localhost:8000 에 접속합니다. 원본 index.html만 열면 3D 번들이 없으므로 먼저 빌드해야 합니다.
진행은 주소와 브라우저별로 저장됩니다. WebGL/모델 로딩 실패 시 기본 PNG 마을에서도 늑대가 다가오고 카드가 지어집니다.

## 검증
- `node test-questions.cjs`: 나이별 문제은행의 수준 규칙·정답 분포·중복 검사.
- `node test-dom.cjs`(`SOFT=1`이면 실패를 모아 보여 줌): 0.12 엔딩 흐름(종 래치·결전 6방패·지는 경우 없음·결전 중 이어하기·새 마을 꾸러미·저장 v1→v3·회관 자동 승급·7세 보호·도둑 여우)과 경제 불변식, 제한시간·수입·카드·저장 이행 규칙, 찍기 대비 읽기 수입 시뮬레이션, 가짜 DOM에서의 흐름(성큼·가게·배우기·쉬기·나이 전환·예전 듣고 고르기 저장 이어받기, 음성 합성을 한 번도 부르지 않음) 검사.
- `node scripts/sim-balance.cjs`: 0.6 문제 경제 밸런스 시뮬레이터(개발용).
- `node scripts/sim-village.cjs end [판 수]`: 0.12 엔딩까지 시뮬레이터(개발용). 나이 × 아이 유형별 엔딩까지 문제 수·분, 10분 붕괴 수를 설계 표와 견줍니다.
- `node scripts/sim-village.cjs [분] [횟수]`: 마을 방어 시뮬레이터(개발용, 0.8 규칙). 아이 유형별 마을 크기·회관 도달 시점·잃은 닭·부서진 건물·늑대가 보이는 시간 비율·무리 크기 비교.
- Playwright 1.56.1과 Chromium/WebKit 설치 후 `node test.cjs`: .pages-build를 제공하며 데스크톱·모바일 크기(320×568 포함), 시작 화면, 나이별 문제 전환, 시간 바와 늑대 정지, 카드와 생성 연출, 저장·이어하기, 실제 시계, 3D 늑대와 주민을 검사합니다.
- 배포 후 실제 URL의 HTML·스크립트·모델·이미지 응답과 커밋을 검사합니다.
- 실제 휴대폰 GPU·효과음·체감 품질은 별도로 확인해야 합니다.

## 현재 학습 범위
7~10세별 읽기 문제 58문항(7세 16·8세 14·9세 14·10세 14)과 상식·수학·영어 435문항이 있습니다(이 가운데 301문항은 자동 생성, `questions-gen.js`). 7세는 낱말과 그림, 8세는 한 문장, 9세는 두 문장, 10세는 짧은 글 이해입니다. 상식·수학·영어는 20문제마다 7세 2·8세 3·9세 5~7·10세 7~10문제로 나이가 많을수록, 진행할수록 늘어납니다. 문제를 읽어 주는 음성은 없습니다. 판마다 문제 순서가 바뀝니다. 듣고 고르기 문제 1,013문항은 0.11에서 없앴고, 읽기 문항이 나이마다 14~16개뿐이라 같은 지문이 자주 돌아옵니다(확충 예정).
난도는 나이로만 정해지며 진단·적응 학습은 아직 없습니다. 문항은 규칙 검사(수학 답은 계산으로 재확인)만 거쳤고 아동·전문가 검수는 받지 않았습니다.
문제마다 제한시간은 없고, 시간 바는 다음 늑대 무리까지 남은 시간입니다. 한 번에 맞혀야 금화와 카드를 받습니다. 늑대는 닭을 물어 가고 건물을 부수지만, 금화를 잃거나 진행이 지워지지는 않습니다.
효과음은 음원 없이 합성하며, 효과음·움직임 설정은 현재 접속 동안 적용됩니다.
녹음·클라우드 저장·학습 개인정보 전송은 없습니다.
