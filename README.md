# 한글 디펜스 0.2 — 마을·전투 개선판

별도 비공개 개발 저장소입니다. 공개 배포 또는 기존 CoopNight 통합본이 아닙니다.

## 실행
`index.html`과 `combat.js`를 같은 폴더에 둡니다.
권장: `python -m http.server 8000` 후 http://localhost:8000 접속.
브라우저 저장은 같은 주소·브라우저에서 유지됩니다.

## 변경
- 크림색·녹색·금색 화면, CSS로 만든 집·타워·지형. 꼬꼬마을 원본 아트는 사용하지 않았습니다.
- 늑대별 체력·이동·성문 피해와 타워 사거리·공격력·공격 간격. 타워 소유만으로 승리하지 않습니다.
- 공격·명중·골드·강화 효과, 간단한 합성 효과음, 성장에 따른 마을 장식.
- 전투 중에도 보유 골드로 강화할 수 있습니다.
- 글자 정답 20골드, 짧은 글 정답 40골드. 독해 보기 5개, 힌트는 문항의 실제 정답을 따릅니다.
- 한국어 음성 우선 선택, 읽기 속도, 효과음·움직임 설정. 음성은 기기의 합성음이며 품질 보장 없음.
- 전투 상태를 주기적으로 저장하고, 재접속하면 일시정지 상태로 재개합니다.
- 320/390px 화면을 고려한 버튼과 문항 배치, 탭 숨김 자동 정지.

## 검사
- `node test-dom.cjs`: 결정적 전투 규칙과 모의 DOM 31개 검사.
- `npm install --no-save playwright@1.56.1`
- `npx playwright install --with-deps chromium webkit`
- `node test.cjs`: Chromium/WebKit, 1366/390/320px, 터치 에뮬레이션, 저장 재개·전투·독해 검사 및 스크린샷.
- GitHub Actions는 최대 10분, 검사 후 종료합니다. 실제 결과는 해당 커밋의 실행 결과로 확인합니다.
- 개발 세션 자체에는 로컬 터미널/브라우저가 없어 JavaScript 실행기에서 31개 모의 검사를 수행했습니다. 실제 기기 음성·모바일 사용감·아동 관찰은 별도입니다.

## 자산 적용 대기
`docs/asset-integration.md` 참고. 기존 로컬 CoopNight에는 접근하지 않았습니다.
원본 캐릭터·건물·애니메이션과 사용 범위 확인 후 이 저장소에 필요한 자산만 가져옵니다.

## 남은 범위
- 실제 원본 아트 및 한국어 음원 적용.
- 실제 휴대폰 한국어 음성·터치·화면과 시각 품질 확인.
- 연령별 학습 적응은 아직 구현하지 않았으며 연령 선택은 기록만 합니다.
- 현재 6글자와 짧은 글 2개는 기술 시연용입니다. 반복에 따른 승률은 학습효과 지표가 아닙니다.
- 성문 0은 완전한 게임오버가 아니며, 다음 문제에서 최소 60으로 회복하는 연습 지원 규칙입니다.
- 효과음/읽기 속도/움직임 설정은 현재 접속 동안 적용됩니다.
- 저장 접근 실패 시 경고하며 진행은 계속됩니다. 클라우드 저장·녹음·개인정보 전송은 없습니다.
