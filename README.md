## 이번 장면
꼬꼬마을에서 인계한 실제 3D 모델로 농장 장면을 구성했습니다. 닭·병아리 배회, 일꾼 이동과 알 운반, 나무와 연기, 타워 발사·반동, 금화 연출을 포함합니다.
0.5에서는 문제를 맞히면 타워·닭·울타리 가운데 하나를 골라 짓고, 고른 것이 연출과 함께 마을에 바로 생깁니다. 나이(7~10세)를 고르면 그 나이의 문제로 바뀝니다.
저장 형식은 0.4와 호환됩니다. 주민의 생활 동작은 장식이며 시간이 지난다고 골드가 생기지 않습니다.
원본 Unity 프로젝트는 수정하지 않았습니다. 자세한 자산/동작 범위는 [장면 구현 메모](docs/living-village.md)를 참고하세요.

## 로컬 실행
Node.js 22와 Python 3 기준:
```sh
npm install --no-save --package-lock=false three@0.180.0 esbuild@0.25.10
node scripts/build-pages.cjs
python -m http.server 8000 --directory .pages-build
```
http://localhost:8000 에 접속합니다. 원본 index.html만 열면 3D 번들이 없으므로 먼저 빌드해야 합니다.
진행은 주소와 브라우저별로 저장됩니다. WebGL/모델 로딩 실패 시 기본 PNG 마을에서 학습·전투는 계속됩니다.

## 검증
- `node test-questions.cjs`: 나이별 문제은행의 수준 규칙·정답 분포·중복 검사.
- `node test-dom.cjs`: 전투·보상·구매·저장·나이 전환·독해 힌트 검사.
- Playwright 1.56.1과 Chromium/WebKit 설치 후 `node test.cjs`: .pages-build를 제공하며 데스크톱·모바일 크기, 나이·모드별 문제 전환, 골라서 짓기와 생성 연출, 전투·저장·이미지 및 3D 주민 이동/정지/움직임 줄이기를 검사합니다.
- 배포 후 실제 URL의 HTML·스크립트·모델·이미지 응답과 커밋을 검사합니다.
- 실제 휴대폰 GPU·한국어 음성·체감 품질은 별도로 확인해야 합니다.

## 현재 학습 범위
7~10세별 소리 문제와 읽기 문제 124문항이 있습니다. 7세는 받침 없는 글자와 낱말, 8세는 받침 있는 낱말과 한 문장, 9세는 헷갈리는 낱말과 두 문장, 10세는 문장 받아쓰기와 짧은 글 이해입니다.
난도는 나이로만 정해지며 진단·적응 학습은 아직 없습니다. 문항은 규칙 검사만 거쳤고 아동·전문가 검수는 받지 않았습니다.
소리 문제 정답은 20골드, 읽기 문제 정답은 40골드이고 닭 1마리마다 정답 보상이 5골드 늘어납니다. 틀려도 골드는 잃지 않습니다.
타워 40골드(최대 5단계), 닭 20골드(최대 6마리), 울타리 20골드(최대 6칸, 늑대를 늦춤).
성문은 다음 문제에서 최소 60으로 회복합니다. 효과음·속도·움직임 설정은 현재 접속 동안 적용됩니다.
녹음·클라우드 저장·학습 개인정보 전송은 없습니다.
