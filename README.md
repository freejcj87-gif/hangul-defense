# 한글 디펜스 임시 프로토타입 0.1

기존 꼬꼬마을 개발 파일과 분리한 독립 HTML 시제품입니다. 기존 프로젝트에 통합되거나 배포된 버전이 아닙니다. 그림은 기존 아트가 아닌 임시 이모지입니다.

## 실행
- ZIP을 풀고 `index.html`을 Chrome/Edge에서 열면 됩니다. 설치와 로그인은 없습니다.
- 권장: 폴더에서 `python -m http.server 8000` 실행 후 같은 컴퓨터에서 `http://localhost:8000` 접속. 정적 서버 사용 시 같은 주소·브라우저에서 저장을 유지하기 쉽습니다.
- 처음 소리 듣기를 눌러 음성을 확인하세요. 기기에 한국어 음성이 없거나 브라우저가 지원하지 않으면 문자 도움말이 표시됩니다.
- 마을 저장은 해당 브라우저 localStorage에만 있습니다. 파일을 옮기거나 브라우저를 변경하면 저장이 유지된다고 보장하지 않습니다.

## 이번 구현 범위
1. 음성 듣기 → 세 글자 중 선택 → 정답 +20골드.
2. 골드 40으로 타워 건설 및 5단계까지 강화.
3. 답을 고른 후 별도의 짧은 방어 장면. 학습 중 적은 멈춰 있습니다.
4. 정답 오류는 비용·시간 제한 없이 다시 시도, 2회 오류 시 도움말.
5. 타워가 있으면 승리·꽃 성장, 없으면 친구의 도움과 성문 10 감소. 성문 파괴 실패 화면은 없습니다.
6. 짧은 지문 2개와 이해 질문, 글자 문제 6개.
7. 골드·타워·성장·진행 저장. 새로고침으로 같은 문제 보상을 반복해서 받는 것을 방지합니다.
8. 휴식 버튼과 탭 숨김 시 자동 정지.

## 교육/게임 디자인상 미완료
- 글자 6개와 지문 2개만 반복하는 기술 시연용 콘텐츠입니다.
- 연령 선택은 기록만 하며 난이도에는 아직 반영하지 않습니다.
- 읽기 속도 측정·개인별 적응·학습효과 검증은 아직 없습니다. 빠른 선택이 읽기 능력 향상이라고 단정할 수 없습니다.
- 타워가 하나라도 있으면 승리하는 고정 규칙입니다. 타워 강화는 방어 시간만 단축합니다. 본격적인 난이도/경제 밸런스가 아닙니다.
- 음성은 브라우저 합성음이며 한국어 음원·발음 검수 미완료입니다.
- 기존 꼬꼬마을 아트 라이선스/소스 연결, 실제 프로젝트 통합, 모바일 실기기 검증, 배포는 미완료입니다.
- 저장 파일 동기화, 계정, 서버, 분석 추적, 음성 녹음, 개인정보 전송은 없습니다.

## 검증
- `node test-dom.cjs`: JS 구문 검사 및 모의 DOM 통합검사 **21개 통과**.
- 검사 범위: 초기 상태, 정답/오답 보상, 힌트, 중복 보상 방지, 저장 재개, 타워 구매, 일시정지, 승리/성장, 전투 재실행 방지, 지문 전환, 초기화, 음성 대체, 타워 없는 경우, 잘못된 저장 데이터.
- `node test.cjs`: Playwright 실제 브라우저 테스트 스크립트 제공. 이 실행환경에서는 Chromium이 `socket() failed: Operation not permitted`로 시작하지 못해 **실행 검증 미완료**입니다. 화면 품질, 실제 음성 재생, 모바일 터치 및 화면 넘침은 확인되지 않았습니다.
- 별도 승인된 실행환경에서 Playwright와 Chromium 설치 후 실제 브라우저 테스트를 실행해야 합니다.

## 기존 세션 인계 순서
1. 이 폴더를 별도 세션의 실행 가능한 작업공간으로 옮깁니다. 기존 CoopNight 폴더에는 덮어쓰지 않습니다.
2. 실기기에서 음성/터치/화면을 검증합니다.
3. 사용자가 보유한 꼬꼬마을 아트의 사용 가능 범위를 확인한 뒤 임시 아트를 교체합니다.
4. 학년·받침·어휘별 문제군, 정확도 우선 단계적 속도 훈련과 읽기 이해 평가를 설계합니다.
5. 검증된 프로젝트/비공개 저장소가 정해지면 별도 브랜치 또는 명시적 신규 프로젝트로 통합합니다.

개인 비공개 저장소에 시제품을 보관합니다. 공개 저장소·호스팅은 만들지 않았습니다.
